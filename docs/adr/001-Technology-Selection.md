# ADR-001: Selection of Tech Stack (React & ASP.NET Core)

## Status
Accepted

## Context
The project requires an enterprise-grade backend capable of handling high concurrency, strict data consistency, and seamless Docker integration.

On the client side, I decided to choose React, a framework I am familiar with, as it provides a modular, component-based architecture.

## Decision
We will use **ASP.NET Core (C#)** for all backend services and **React** for the frontend application.
